# Steel-Tide
Browser build of [Steel Tide](https://github.com/vtisza/MetalMarines) (v0.3.0, Godot 4.3 web export),
published with GitHub Pages: **Settings -> Pages -> Deploy from a branch -> `main` / `/ (root)`**.

Single player runs entirely in the browser. Online multiplayer needs the WebSocket relay, which
GitHub Pages cannot host; point the game at one with `?relay=wss://<host>/relay`.
